# TXT / LOG 高亮一致性修复

日期：2026-11-03。

`.txt`、`.log` 和 `.log.*` 统一使用 `[log]` 文件类型和 `log` 语法。
该规则放在通用 `*.*` 与手册文件 `*.1` 规则之后，避免它们按反向优先级抢先匹配。
无扩展名文本保留原配置，其他语言规则不变。

普通文本中的完整大写 `WARN`、`ERROR` 及正文星号使用相同高亮。
`WARNING`、`XERROR`、`ERROR_code` 和小写 `warn/error` 保留普通文字颜色。

已有个人 `~/.mj/ftyperc` 会优先于安装包配置，安装更新不会覆盖个人规则。
本机个人文件中的同版默认规则已按同样方式修正，修改前保留了独立备份。
其他机器若保留旧个人规则，需要同步将 `*.txt` 加入后面的 `[log]` 段；重新启动 MiJoe 后生效。
