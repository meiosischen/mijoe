已支持的 Vim 命令
Normal 普通模式；Insert 插入模式；Visual 选择模式。
PageDown / Space 下一页；PageUp / b 上一页；q / Esc 关闭帮助。

【移动与定位】
h j k l / 方向键：左、下、上、右移动。
w / b / e：下个词、上个词、词尾。
0 / ^ / $ / Home / End：行首、首个非空白字符、行尾。
gg / G / 数字G：首行、末行、指定行；:数字 跳到行号。
Ctrl+u / Ctrl+d / PageUp / PageDown：半页、整页移动。
f字符 / F字符：在当前行向右、向左找到字符。
t字符 / T字符：在当前行停到目标字符前、后。
; / ,：按原方向、相反方向重复 f/F/t/T。
%：匹配 () [] {}，支持跨行与嵌套。
%：光标在 /* 或 */ 上时匹配 C 注释的另一端。
%：匹配 #if/#ifdef/#ifndef/#elif/#else/#endif。
1% 至 100%：跳到文件相应比例的行。
次数：2fx、3j、2d3w；查找失败取消待执行操作。

【插入与编辑】
i / a：在当前字符前、后插入。
I / A：在行首非空白处、行尾插入。
o / O：在下方、上方新建一行并插入。
Esc / Ctrl+[：结束插入或选择，返回 Normal。
Insert 中：Enter 换行；Backspace / Delete 删除字符。
Insert 中：方向键、Home/End、PageUp/PageDown 移动。
x / Delete：删除当前字符；可带次数。
d移动 / c移动 / y移动：删除、修改、复制移动范围。
dd / cc / yy：删除、修改、复制整行；可带次数。
D / C：删除、修改到行尾；可带行数。
p / P：在光标后、前粘贴内部寄存器内容。
u / Ctrl+r / .：撤销、重做、重复上次修改。
示例：dw、cfx、dFx、y%、v%d、2d3fx。

【选择与搜索】
v / V：按字符、按整行选择；再按一次取消。
字符/整行选择中使用移动键扩展范围，y/d/c/x 复制、删除或修改。
Ctrl+V：矩形选择；h/j/k/l、方向键或次数调整范围。
矩形 I / A：左侧插入、右侧追加，输入后 Esc 应用到各行。
列插入输入期间先显示首行，Esc 后复制到其余所选行。
示例：行首 Ctrl+V、2j、I，输入 // 后 Esc，给三行加前缀。
矩形 $A 在每行行尾追加；u / Ctrl+r 整批撤销、重做。
I 跳过未到达插入列的短行；A 补空格；Tab 内插入会拆分 Tab。
列插入支持中文和单行粘贴；换行或移动光标后只编辑首行。
矩形中再按 Ctrl+V 或 Esc 取消，v/V 切换为字符/整行选择。
/表达式 / ?表达式：向前、向后搜索；Enter 执行。
n / N：重复搜索、反向重复；使用 JOE 正则表达式。

【文件与缓冲区】
:e 路径 / :edit 路径：打开文件，保留已有未保存内容。
:enew：新建未命名缓冲区。
:ls / :buffers：显示缓冲区编号、当前项和修改标记。
:bn / :bnext；:bp / :bprevious：下个、上个缓冲区。
:b 编号 / :buffer 编号：按编号切换。
:bd / :bdelete：删除当前缓冲区；有修改需使用 :bd!。
:w / :write：保存当前文件。
:w 路径：写出副本，保留当前文件名；! 允许覆盖。
:saveas 路径 / :sav 路径：另存为并切换文件名。
:q / :quit：退出；有修改时 :q! 明确放弃。
:wq：保存成功后退出；保存失败保留编辑器和修改。
:x：有修改时保存，然后退出。
路径支持空格、中文和 Windows 反斜杠，可整体加引号。

【帮助、菜单与主题】
:help / :h：本支持列表；PageDown/PageUp 翻页，q/Esc 关闭。
Ctrl+K H：JOE 原始帮助；PageDown/PageUp 切页，再次按键关闭。
Ctrl+T：开关 JOE 选项菜单，不改变 overtype；菜单中 T/t 切换 overtype。
菜单中方向键选择，Enter 确认，Ctrl+C 取消。
Ctrl+T 然后 P：开关 picture mode；移动可越过行尾，输入自动补空格。
Picture mode 下 Normal 用 h/j/k/l 或方向键；Insert 用方向键。
Ctrl+K T：缩小窗口；不是选项菜单。
切换主题：Ctrl+T，然后 S，输入主题名并按 Enter。
主题输入框可按 Tab 查看候选，Ctrl+C 取消。
:colors / :colorscheme：直接显示主题选择菜单。
主题菜单中方向键选择、PageUp/PageDown 翻页、Enter 应用。
:colors 主题名：直接应用，如 :colors gruvbox。
主题即时生效，不会修改文件内容。
:set novim：切换到 JOE 键位；启动参数 -novim 同效。
macOS 用终端粘贴；Windows Insert 中支持 Shift+Insert。

【范围】
只列出本版本已支持命令，未列出命令不保证可用。
矩形模式目前仅支持 I/A，不支持矩形删除、修改、复制粘贴。
不支持命名寄存器、文本对象、Vimscript、完整 Ex。
主题是否跨会话保留取决于 joe_state 设置；不改写用户配置。
