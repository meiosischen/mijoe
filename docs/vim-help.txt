已支持的 Vim 命令
Normal 普通模式；Insert 插入模式；Visual 选择模式。
PageDown / Space 下一页；PageUp / b 上一页；q / Esc 关闭帮助。

【最近文件与个人配置】
:recent：居中选择最近打开的 200 个文件，最新在前；长路径自动折行。
上/下或 Ctrl+P/N 选择，PageUp/PageDown 翻页，Enter 打开，Esc/Ctrl+C 取消。
列表超出高度时显示滚动条；恢复 RO/RW、TEXT/HEX、只读懒加载及软折行状态。
打开前检查文件，已经不存在的文件会报错并移除记录；权限等其他错误保留记录。
个人配置集中在 ~/.mj；config 为选项，joerc 为按键配置，state 为状态，.recent 为最近文件。
macOS 字号/行距在 macos.json，Windows 窗口设置在 windows.ini。旧配置保留作备份。

【软折行】
默认关闭；Ctrl+T → Q Soft wrap 切换，:set wrap / :set nowrap 开启 / 关闭。
已有长行按 Right Margin 和窗口正文宽度折行显示，不改变文件内容；W Word wrap 独立控制输入时硬换行。
j/k、上下键按逻辑行移动；PageUp/PageDown、滚轮和鼠标按屏幕位置处理。调整窗口和边界立即重排。
Hex、Picture、隐藏 ANSI 模式和 shell 窗口沿用原有显示。

【顶部文件路径】
状态栏显示绝对路径；鼠标拖选复制，图形窗口双击复制完整路径（含未显示部分）。
独立于正文选区，不改变光标或模式。控制台需 -mouse 和支持 OSC 52 的终端；也可 Shift 拖选并使用终端复制。

【移动与定位】
h j k l / 方向键：左、下、上、右移动。
Normal/Insert/Visual：Ctrl+A/E 行首/行尾，Ctrl+P/N 上行/下行。
Ctrl+B/F 退/进一个字符；Ctrl+K 后保留原有组合键功能。
w / b / e：下个词、上个词、词尾。
0 / ^ / $ / Home / End：行首、首个非空白字符、行尾。
gg / G / 数字G：首行、末行、指定行；:数字 跳到行号。
Ctrl+u / Ctrl+Shift+U（大写 U）：整页上翻 / 下翻，等同 PageUp / PageDown。
上述翻页键在 Normal / Insert / Visual 都可用；Ctrl+d 在 Normal/Visual 下翻半页。
终端需能区分 Ctrl+Shift+U；否则下翻整页请用 PageDown。
f字符 / F字符：在当前行向右、向左找到字符。
t字符 / T字符：在当前行停到目标字符前、后。
; / ,：按原方向、相反方向重复 f/F/t/T。
%：匹配 () [] {}，支持跨行与嵌套。
%：光标在 /* 或 */ 上时匹配 C 注释的另一端。
%：匹配 #if/#ifdef/#ifndef/#elif/#else/#endif。
1% 至 100%：跳到文件相应比例的行。
次数：2fx、3j、2d3w；查找失败取消待执行操作。

【插入与编辑】
macOS/Windows 图形窗口：F1/F2 增大/减小字号 1 点，F3/F4 增大/减小行距 1 像素，立即刷新并记住设置。
i / a：在当前字符前、后插入。
I / A：在行首非空白处、行尾插入。
o / O：在下方、上方新建一行并插入。
Esc / Ctrl+[：结束插入或选择，返回 Normal。
Ctrl+C：关闭 grep/帮助/列表/菜单，取消命令输入；有选区先取消选择。
编辑窗口中 Ctrl+C 按 JOE 原版退出：必要时确认丢弃修改，有后台缓冲区先返回它，否则关闭窗口。
Insert 中：Enter 换行；Backspace / Delete 删除字符。
Insert 中：方向键、Home/End、PageUp/PageDown 移动。
x / Delete：删除当前字符；可带次数。
d移动 / c移动 / y移动：删除、修改、复制移动范围。
dd / cc / yy：删除、修改、复制整行；可带次数。
D / C：删除、修改到行尾；可带行数。
p / P：在光标后、前粘贴内部寄存器内容。
u / Ctrl+r / .：撤销、重做、重复上次修改。
示例：dw、cfx、dFx、y%、v%d、2d3fx。

【文本对象】
iw / aw：当前单词内部 / 单词及相邻空白；标点与关键词分开。
iW / aW：当前 WORD 内部 / WORD 及相邻空白；WORD 按空白分隔。
i( / a(、i[ / a[、i{ / a{、i< / a<：括号内部 / 包含括号。
括号右侧写法等价：i) a) i] a] i} a} i> a>；ib/ab 等于 i(/a(，iB/aB 等于 i{/a{。
i" / a"、i' / a'、i` / a`：引号内部 / 包含引号及相邻空白，限当前行，跳过转义引号。
用于 Visual 或 d/c/y：viw、vaw、diw、ci"、yi(、da{。
次数：v2iw、d2aw、2di(；括号次数向外选择嵌套层。
iw 的次数将词间空白计为一段；aw 的次数只计单词。
Visual 中重复文本对象扩展选择；Esc 取消尚未完成的 i/a 前缀。

【选择与搜索】
v / V：按字符、按整行选择；再按一次取消。
字符/整行选择中使用移动键扩展范围，y/d/c/x 复制、删除或修改。
Ctrl+V：矩形选择；h/j/k/l、方向键或次数调整范围。
矩形 I / A：左侧插入、右侧追加，输入后 Esc 应用到各行。
列插入输入期间先显示首行，Esc 后复制到其余所选行。
示例：行首 Ctrl+V、2j、I，输入 // 后 Esc，给三行加前缀。
矩形 $A 在每行行尾追加；u / Ctrl+r 整批撤销、重做。
I 跳过未到达插入列的短行；A 补空格；Tab 内插入会拆分 Tab。
列插入支持中文和单行粘贴；换行或移动光标后只编辑首行。
矩形中再按 Ctrl+V 或 Esc 取消，v/V 切换为字符/整行选择。
/表达式 / ?表达式：向前、向后搜索；Enter 执行。
*：向后搜索光标附近的完整单词；支持次数、回绕和 n/N。
n / N：重复搜索、反向重复；使用 JOE 正则表达式，匹配项保持高亮。
:noh / :nohlsearch：清除搜索高亮，n/N 再次搜索时恢复。

【文件与缓冲区】
:e 路径 / :edit 路径：打开文件，保留已有未保存内容。
:enew：新建未命名缓冲区。
:ls / :buffers：逐行列出完整路径、编号及当前/修改/只读/懒加载标记，可翻页。
macOS 窗口版汇总所有窗口的缓冲区并按窗口分组；终端版列出当前进程的缓冲区。
PageUp/PageDown 翻页，q/Esc 关闭；:b/:bn/:bp 的编号及切换范围仍属于当前窗口。
:bn / :bnext；:bp / :bprevious：下个、上个缓冲区。
:b 编号 / :buffer 编号：按编号切换。
:bd / :bdelete：删除当前缓冲区；有修改需使用 :bd!。
:w / :write：保存当前文件。
:w 路径：写出副本，保留当前文件名；! 允许覆盖。
:saveas 路径 / :sav 路径：另存为并切换文件名。
:q / :quit：退出；有修改时 :q! 明确放弃。
:wq：保存成功后退出；保存失败保留编辑器和修改。
:x：有修改时保存，然后退出。
路径支持空格、中文和 Windows 反斜杠，可整体加引号。

【帮助、菜单与主题】
:help / :h：本支持列表；PageDown/PageUp 翻页，q/Esc 关闭。
Ctrl+K H：JOE 原始帮助；PageDown/PageUp 切页，再次按键关闭。
Ctrl+T：开关 JOE 选项菜单，不改变 overtype；菜单中 T/t 切换 overtype。
菜单中方向键选择，Enter 确认，Ctrl+C 取消。
Ctrl+T 然后 P：开关 picture mode；移动可越过行尾，输入自动补空格。
Picture mode 下 Normal 用 h/j/k/l 或方向键；Insert 用方向键。
Ctrl+K T：缩小窗口；不是选项菜单。
切换主题：Ctrl+T，然后 S，输入主题名并按 Enter。
主题输入框可按 Tab 查看候选，Ctrl+C 取消。
:colors / :colorscheme：直接显示主题选择菜单。
主题菜单中方向键选择、PageUp/PageDown 翻页、Enter 应用。
:colors 主题名：直接应用，如 :colors gruvbox。
主题即时生效，不会修改文件内容。
:set novim：切换到 JOE 键位；启动参数 -novim 同效。
macOS 用终端粘贴；Windows Insert 中支持 Shift+Insert。

【范围】
只列出本版本已支持命令，未列出命令不保证可用。
矩形模式目前仅支持 I/A，不支持矩形删除、修改、复制粘贴。
不支持命名寄存器、文本对象、Vimscript、完整 Ex。
主题是否跨会话保留取决于 joe_state 设置；不改写用户配置。

【大文件与二进制】
大于 512 MiB 的文件先提示：L/Enter 只读懒加载，N 正常打开，Esc/C 取消。
macOS 原生窗口提供相同的三个按钮；二进制文件自动进入 HEX 模式。
只读懒加载按需读取约 1 MiB 原文件窗口，支持超过 4 GiB 的文件偏移。
懒加载禁止编辑、保存和另存为，不扫描全文件建立行号或语法索引。
gg / G：文件首尾；数字%：按字节比例跳转；:数字 / 数字G：按行号定位。
/字面文本、?字面文本、*、n/N 可跨区搜索；懒加载不支持一般正则。
行号定位与搜索可能扫描文件，Esc / Ctrl+C 可取消，内存不随文件增长。
远距离跳转后未知行号显示 ?，状态栏 B 显示原文件绝对字节偏移与大小。
只复制当前已加载区域中的选择；翻页换区时清除选择，不支持全文件全选。
懒加载文件在同一会话中不能分屏共享；可在独立窗口再次打开。
源文件被外部修改后停止换区和搜索，需要关闭后重新打开。
命令行：mj -lazy 文件 强制只读懒加载；-large_threshold 512 设置阈值（MiB）。

【当前文件 grep】
内置管道：grep / awk / head / more / less 可用 | 任意组合，全部处理当前文件。
:awk '{print $1,$3}'；:awk -F ',' '$3>=100 {print NR,$1}'；支持 $0、NR、NF、比较和 /正则/ 条件。
:grep ERROR | awk '{print $2,$5}' | grep timeout | head -n 20 | less
:head 默认前 10 行，-n N / -nN 指定行数；more/less 为只读分页，Space/b 或 PgDn/PgUp 翻页。
窗口行号和跳转指向原文件，awk NR 从当前输入流计数；字符串或正则里的 | 需要引号。
管道 -f 导出最终纯文本；console 新 buffer，原生 macOS 新窗口；单独 grep -f 保持行号前缀。
最多 16 阶段、1 MiB/行、4096 字段、64 print 项、10000 结果、64 MiB 输出，超限提示。
awk 不支持算术、赋值、循环、数组、函数或 BEGIN/END；详见 docs/internal-pipelines.md。
:grep 表达式：列出当前文件的匹配行，显示行号和内容，不运行外部 shell。
:grep -f 表达式：完整匹配行写入新的纯文本临时窗口，可编辑、另存为；原文件和光标不变。
-f 在 console/终端中新建当前窗口的缓冲区，用 :ls、:bn/:bp、:b 编号、:bd 管理。
-f 在 macOS 窗口版继续打开独立窗口，Windows 图形版保留新编辑窗口；结果以“行号: 内容”排列。
-f 最多 10000 行，到顶时末尾标注；总输出最多 64 MiB，超出时取消并提示缩小搜索范围。
grep 结果中 Left/Right：统一左右移动所有结果的正文视口，行号固定；标题 X 为起始显示列。
结果居中显示，约占半屏面积；上下箭头 / Ctrl+P/N / j/k 移动并预览。
PageUp/PageDown 翻页，Home/End 或 g/G 到首尾；支持窗口缩放。
Enter 确认当前位置，Esc/Ctrl+C/q 取消并恢复原光标和滚动位置。
普通文本支持 JOE 正则；只读懒加载使用字面匹配，流式扫描可按 Esc 取消。
每行显示一项，最多 10000 项；达到上限标记 limit，预览内容截取开头。

【Vim 寄存器】
未命名寄存器 "：最近一次复制或删除；0：最近一次默认复制，删除不覆盖 0。
1～9：删除历史；-：默认的小范围删除；a～z：命名寄存器；A～Z：追加到同名小写寄存器。
"ayy 复制一行到 a；"ap / "aP 粘贴 a；"_dd 删除而不写入任何寄存器。
命名复制不覆盖 0；寄存器保存在当前编辑器会话内。
命令栏或 Insert 中 Ctrl+R，接 0 / " / a 等寄存器名，插入内容。
命令栏另支持 /（搜索文本）、:（上次 Ex 命令）、%（当前文件名）。
Visual 或 Ctrl+K Ctrl+B / Ctrl+K Ctrl+K 标记区域后，按 :、/、? 时将选择复制到 0。
示例：选择 WARN 后，:grep Ctrl+R 0 Enter，列出当前文件的全部匹配行。
命令栏中的多行内容转换为空格，插入不会自动执行；超过命令栏容量时拒绝整次插入。
矩形标记按多行文本复制；尚不提供系统剪贴板 +/* 或表达式 = 寄存器。

【寄存器查看与宏】
" 后显示寄存器名提示，接 a 等名称后回显所选寄存器；Esc 取消。
:reg / :registers：查看寄存器类型、字节数与内容；:reg a 或 :reg 0a 查看指定项。
控制字符以 <NL>/<Tab> 等显示，每项预览前 16 KiB；PageUp/PageDown 翻页，q/Esc 返回。
F5：开始键盘宏录制；再次 F5 结束并保存为最近一次宏，状态栏显示 REC。
F6：回放最近一次宏；回放前使用与录制开始时相同的模式，建议在 Normal 开始与结束。
:macro / :macros：只读查看宏状态、键数与按键序列；方向键、Esc 等显示为可读名称。
宏记录编辑区键盘输入、Ex 输入、中文、终端粘贴和 JOE Ctrl+K 组合键；不记录鼠标与原生菜单操作。
Ctrl+C 中断回放；命令错误停止回放；录制期间 F6 不回放，避免递归。
宏保存在当前编辑器会话，超过 65536 键则丢弃新录制并保留之前的宏。

【Ex 文本替换】
:s/旧/新/：替换当前行第一处；:s/旧/新/g 替换当前行全部。
:%s/旧/新/g：全文替换；:2,10s/旧/新/g 指定行范围；支持 .、$、+/- 偏移。
Visual 选择后按 : 输入 s/旧/新/g，自动带入 '<,'> 行范围；grep 等命令保留原用法。
标志 g=每行全部、i=忽略大小写、I=区分大小写、c=逐项确认、e=无匹配不报错。
c 确认：y 替换、n 跳过、a 全部、l 替换此处并结束、q/Esc/Ctrl+C 停止。
支持 . * [] ^ $、\(分组\)、\+、\?、\=、\{m,n}、\< / \> 单词边界。
替换串 & 或 \0 为整项、\1…\9 为分组；\& / \\ 为字面字符、\r 换行、\t Tab、\n NUL。
空旧串复用上次搜索；单独 :s 重复上次替换（不继承 g/c 等标志）。一次 u 撤销整次替换。
支持 :substitute；分隔符也可用 # 等。只读、Hex 和懒加载不执行替换。
尚不支持跨行正则、模式反向引用、交替 \|、magic 修饰、表达式/大小写转换替换、尾随计数或管道。
重复次数上限 1000，最多 9 个捕获分组；其他高级 Vim 正则以错误提示拒绝。

【行位置百分比】
右上角 R / C 后显示“当前逻辑行 ÷ 全部逻辑行 × 100”的整数百分比，向下取整。
末尾换行不多算一行，空文件显示 100%；软折行不增加总行数。Hex 按每 16 字节一行计算。
只读懒加载文本尚未掌握全部行数时显示 --%，不会为了百分比扫描整个文件；原有 RO-LAZY 字节进度独立保留。

【临时字面高亮】
:set-hl "gogogo 123"：按完整短语匹配，包含中间的一个空格。
:set-hl gogogo 123：分别匹配 gogogo、123；可混用：:set-hl "two words" ERROR。
多次执行追加，重复词去重；:set-hl 不带参数查看当前词；:clear-hl 清除当前文件全部临时词。
区分大小写，按字面子串匹配，正则符号没有特殊含义；" 和反斜杠可用 \"、\\ 转义。
临时匹配使用黄色背景；Visual/JOE 选区和 / 搜索高亮优先；:noh 不清除临时词。
仅随当前打开的缓冲区存放；切换缓冲区保留，:bd 真正关闭或退出后消失。
.recent 保留文件与打开模式，不保存临时词；重新打开已关闭文件不会恢复高亮词。
只读、大文本关闭语法高亮时及文本懒加载均可用，Hex 视图不添加、不显示临时高亮。
只检查显示区域及最长词所需的边界，不扫描全文、不修改文件、撤销记录或语法高亮设置。
最多 32 个词，每词 1024 UTF-8 字节，总计 8192 字节；空词、未闭合引号与超限整次拒绝。
