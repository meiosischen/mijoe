# 行号临时高亮验证

日期：2026-11-04。

`:set-hl :1` 整行高亮第一条逻辑行，可混用 `:set-hl :1 :5 ERROR`。
双引号内的 `":1"` 仍为字面匹配；行号按当前文档的固定数字解释，不跟随原内容移动。
行号与文本合计 32 项，统一去重、原子校验、由 `:clear-hl` 清除；规则归当前缓冲区，关闭后不恢复。

行背景覆盖文字、空白行、水平裁剪和软折行右侧空白；选区与搜索仍优先。
只检查显示行和已有元数据。懒加载区域使用已知的全局行基数，行号未知时不误用区域相对行号，
不为行高亮扫描全文。EOF 下方不存在的显示行不染色。
