# 临时高亮使用纯亮黄色

日期：2026-11-04。

`:set-hl` 的行号和文本高亮默认使用黑色文字、纯亮黄 `#FFFF00` 背景，
包括 CSV 表头、空白行以及软折行右侧空白。选区与搜索的显示优先级不变。
原实现直接使用 ANSI 调色板第 11 色，窗口终端的默认 RGB 为 `#FFFF40`，会带一点浅色。
现在通过独立的 temporaryhl 内建配色分配准确的 GUI RGB；256 色终端使用固定色号 226，
低色彩终端回退到亮黄，避免影响普通语法颜色或其他终端调色板项目。

macOS：102 项临时高亮原生检查通过，CSV 表头逐单元核对背景 `#FFFF00` 和前景 `#000000`；
另有 138 项原生回归及 256 色 PTY 的实际 SGR 输出检查通过。
VC6：Release / Debug 的独立 EXE 与 DLL 版本构建通过，每版执行 4 个行号及字面高亮用例。
Windows 命令回归共 16 项通过；颜色像素由 macOS 原生窗口验证。
Wine 检查和 PE 静态检查不能替代真实 XP 运行验收。

本机窗口 App 和控制台已更新，签名、前后端文件及 mj 软链核对通过；
已重新打开用户 CSV 并执行 `:set-hl :1`，目视确认表头纯亮黄，光标恢复到第二行。
