# 命令栏历史验证

日期：2026-11-03。

`:history` 按最新优先打印最近 200 条实际回车提交的 `:`、`/`、`?` 输入。
普通编辑按键、取消的输入、空输入、历史查询本身和原生菜单操作不计入。
失败的命令仍记录；寄存器展开记录最终输入；宏录制和回放分别显示 REC / PLAY。
宏内的普通编辑按键不记录，完整宏仍用 `:macro` 查看。

记录保存在个人目录 `.history`，独立于 joe_state；使用文件锁合并多进程写入、
同目录临时文件原子替换和递增序号。损坏或不可读的历史保留原件，记录失败不阻止命令执行。
显示时转义控制字符，长命令按可视宽度换行；只读查看器支持 PgDn/PgUp 和 q/Esc/Ctrl+C。
分页仅为可见页构造显示文本，行索引按实际折行数量分配。

`:set-hl` 等命令的输入文字会进入历史，但打开文件时不执行历史，不恢复临时高亮状态。
本功能只记录更新后提交的输入，无法补回以前没有保存的命令。
