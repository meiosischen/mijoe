# 内置文本管道

在 `:` 命令栏输入。所有命令处理当前文件，普通缓冲区包含尚未保存的编辑，
只读懒加载文件按块读取。Windows XP 无需安装外部 awk、grep 或分页程序。

```text
:awk '{print $1,$3}'
:awk -F ',' '$3 >= 100 {print NR,$1,$3}'
:grep ERROR | awk '{print $2,$5}' | grep timeout | head -n 20 | less
:awk '$2 ~ /WARN|ERROR/ {print $0}' | more
:head -n 200 | grep ERROR
:more | grep WARN | awk '{print NR,NF,$2}' | head -n 5
```

五个命令可以重复、任意组合，`|` 两侧可省略空格。`head -n 100 | grep ERROR` 搜索前 100 行；
`grep ERROR | head -n 100` 取前 100 条匹配结果。正则或字符串中的 `|` 应放在引号内，
例如 `grep 'WARN|ERROR'`；awk 的 `/正则/`、花括号和字符串内的竖线不会被拆成管道。

## awk 子集

默认按空白分列，忽略首尾分隔空白。`-F` 指定一个字符：`-F ','`、`-F','`、`-F '\t'`，
也支持单个中文字符或 emoji。指定字符分隔符时保留空字段；不处理 CSV 引号或多字符/正则分隔符。

| 写法 | 含义 |
| --- | --- |
| `$0` | 进入当前 awk 阶段的完整文本 |
| `$1`、`$2`… | 对应字段；不存在的字段为空字符串 |
| `$NF` | 最后一个字段 |
| `NR` | 进入当前 awk 阶段的记录序号，从 1 开始 |
| `NF` | 当前记录的字段数 |
| `{print}`、`{print $0}` | 输出完整文本 |
| `{print $1,$3}` | 字段之间输出一个空格 |
| `{print $1 ":" $3}` | 相邻表达式直接拼接 |
| `/ERROR/ {print $2}` | 整行匹配正则后输出 |
| `$2 ~ /timeout/`、`$2 !~ /timeout/` | 字段匹配、不匹配正则 |
| `$3 >= 100 {print $1}` | 单个比较条件 |
| `NR <= 10` | 无 print 动作时输出通过条件的完整记录 |

比较支持 `== != < <= > >=`。数值或完整数值字段按数值比较；普通字符串、双引号常量按字符串比较。
字符串可用 `\t`、`\"`、`\\`，不接受换行转义。正则使用现有 JOE 引擎，
字符范围可写 `[A-Z]`；不提供系统 awk 的完整正则兼容性，例如 POSIX 命名类 `[[:upper:]]` 不受支持。
支持单个条件和单个 print 动作；不支持算术、赋值、布尔组合、数组、循环、函数、BEGIN/END、文件参数或外部命令。

## head、more、less

`head` 默认前 10 行；`head -n N` / `head -nN` 指定非负行数。`-n 0` 不读取源记录。
达到行数后停止上游扫描，不会先把整个文件或所有 grep 结果装入内存。

`more`、`less` 在这一版使用同一套只读结果分页窗口，位于管道中间时原样传递文本。
窗口沿用 grep 的居中布局：上下箭头、Ctrl+P/N、j/k 移动预览；Space/PageDown 下一页，
b/PageUp 上一页；g/G、Home/End 首尾定位；左右箭头平移正文，行号固定。
Enter 关闭并保留预览位置；Esc、q、Ctrl+C 关闭并恢复原光标、顶部和水平位置。

左侧行号始终是原文件行号，不参与后续 grep/awk 处理；awk NR 是当前输入流序号。

## 导出最终结果

组合管道中任意命令的选项位置加 `-f`，在全部阶段完成后导出最终纯文本：

```text
:grep -f ERROR | awk '{print $2,$5}' | head -n 20
:awk -f -F ',' '{print $1,$3}' | grep timeout
:head -f -n 30
:more -f
```

console 在当前编辑窗口新建可编辑缓冲区，用 `:ls`、`:bn/:bp`、`:b 编号` 管理；
macOS 原生版开独立窗口，Windows 图形版开新编辑窗口。结果未命名，用 `:saveas 路径` 保存。
管道导出不包含界面行号。单独的原有 `:grep -f 表达式` 仍导出“行号: 内容”。
这里的 `-f` 是结果导出选项，不是 awk 的程序文件选项。

## 处理边界

最多 16 阶段，每行解码后最多 1 MiB，每个 awk 记录最多 4096 字段、64 个 print 项。
结果最多 10000 行，到顶时窗口与导出末尾明确标记；结果正文最多 64 MiB。
过滤发生在结果上限之前，前面几万条不匹配记录不会遮掉后面的匹配。
窗口每行预览约 1 KiB，导出保留完整输出。more/less 同样受结果上限约束。

语法错误、超限、取消或源文件变化会提示并恢复原位置，不导出失败的部分结果。
空结果仅提示，不新建结果缓冲区。HEX 文件不能运行文本管道。
