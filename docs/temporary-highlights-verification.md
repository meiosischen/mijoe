# 临时字面高亮验证

日期：2026-11-03。

`:set-hl "gogogo 123"` 匹配含空格的完整短语，`:set-hl gogogo 123` 分别匹配两项。
支持混合输入、追加去重、列表查询和 `:clear-hl`；不解释正则，区分大小写，匹配字面子串。
临时词归当前打开的缓冲区所有，切换保留，真正关闭后释放。
`.recent` 保留原文件路径和模式，不新增临时词字段；关闭后重开或退出后重启不恢复临时词。

显示层使用当前缓冲区缓存的字面匹配器。每个显示行只检查可见位置及最长词所需的前置边界，
合并重叠匹配，兼容 UTF-8、水平裁剪和软折行。不建立全文索引，不读取新的懒加载区域。
语法高亮关闭、大文本自动禁用语法高亮及只读文本仍可使用；Hex 视图不显示或添加。
没有临时词时不分配匹配指针，并跳过每字符匹配调用。

亮黄色背景/黑色前景使用终端调色板；选区和搜索高亮优先。清除搜索不清除临时词。
最多 32 项，每项 1024 UTF-8 字节，总计 8192 字节；错误输入整次拒绝，不破坏已有词集。
详细用法见 [操作说明](vim.md#临时字面高亮) 和内置 `:help`。
