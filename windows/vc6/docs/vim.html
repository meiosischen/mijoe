Windows VC6 edition: pop-up terminals and F1-F4 are disabled.

# Vim 基础操作

默认启用 Vim 操作，启动处于 Normal 模式。`joe -novim`（或配置中的
`--vim`）使用传统 JOE 键位；Vim 命令 `:set novim` 可关闭。

公共实现位于 `joe/vim.c`，Windows XP/VC6 与 UNIX 共用。
顶部状态栏用 `[N]`、`[I]`、`[V]` 分别表示 Normal、Insert、Visual；按字符、按行及矩形选择统一显示 `[V]`。

- 移动：`h j k l`、方向键、`w b e`、`0 ^ $`、`gg G`、`数字G`。
- 翻页：`Ctrl+u` 上翻整页，`Ctrl+Shift+U`（大写 U）下翻整页，等同 `PageUp/PageDown`，
  Normal/Insert/Visual 都支持。`Ctrl+d` 保留 Normal/Visual 下翻半页。
  macOS/Windows 窗口直接区分 Shift；终端需要发送独立的 CSI-u 或 modifyOtherKeys 编码，
  传统终端若将两个组合键都发成 ASCII 21，则用 `PageDown` 下翻。
- 行内定位：`f字符` 向右、`F字符` 向左到目标；`t字符` / `T字符` 停在目标前/后。
  `;` 按原方向重复，`,` 反向重复；如 `2fx`、`3;`。查找限于当前行，支持中文目标。
- 配对跳转：`%` 匹配 `()[]{}`，支持嵌套和跨行；光标位于 C 注释分隔符时匹配 `/* */`，
  条件编译行支持 `#if/#ifdef/#ifndef/#elif/#else/#endif`。`50%`、`100%` 按文件比例跳转。
- 插入：`i a I A o O`；`Esc` 或 `Ctrl+[` 返回 Normal。
- macOS/Windows 图形窗口：`F1/F2` 增大/减小字号 1 点，`F3/F4` 增大/减小行距 1 像素，立即刷新并记住设置。
  Windows 保持外框尺寸，重新计算行列数与光标尺寸；无修饰键生效，字号范围 6–72 点，行距上限 32 像素、行高下限 2 像素。
- 编辑：`x dd dw d$ cc cw yy yw p P`；次数可以出现在操作符前后，如 `2d3w`。
- 撤销：`u`；重做：`Ctrl+r`；重复修改：`.`。
- 选择：`v` 按字符、`V` 按行，移动扩展选区，`y d c` 操作，`Esc` 取消。
- 文本对象：`iw/aw/iW/aW`、`i/a` 搭配 `() [] {} <>` 或三种引号；详见下文。
- 列插入：`Ctrl+V` 进入矩形选择，方向键或 `h/j/k/l` 调整；`I` 在左边界插入，
  `A` 在右边界追加，输入后按 Esc 应用到所选各行。`u` / `Ctrl+r` 整批撤销、重做。
- 搜索：`*` 向后搜索光标附近的完整单词（支持次数和回绕）；`/表达式`、`?表达式`、`n N`，使用 JOE 的标准正则表达式引擎，可见匹配项持续高亮。
  `:noh` / `:nohlsearch` 清除高亮，`n/N` 再次搜索时恢复。
- 帮助：`:help` / `:h` 列出本版本支持的命令及简介，PageDown/PageUp 翻页，`q` / Esc 关闭。
- JOE 菜单：`Ctrl+K H` 打开原始帮助，PageDown/PageUp 切页，再次按键关闭；
  `Ctrl+T` 打开选项菜单，再按一次关闭，保持 overtype 状态；菜单中的 `T/t` 才切换 overtype。
  `Ctrl+K T` 沿用原绑定，用于缩小窗口。
- Picture mode：`Ctrl+T` → `P` 开关。在 Normal 中用 `h/j/k/l` 或方向键，Insert 中用方向键，
  可移动到行尾外；输入时自动补空格，长短行之间保留屏幕列。`i` 在当前列插入，`a` 在下一列插入，
  `I/A` 仍定位到实际行首/行尾。向下越过文件末尾会扩展空行，可撤销；只读缓冲区禁止扩展。
- 主题：`:colors` / `:colorscheme` 显示选择菜单，方向键选项、PageDown/PageUp 翻页、Enter 应用、Ctrl+C 取消；
  `:colors gruvbox` 可直接切换。原有入口是 `Ctrl+T` → `S Color scheme` → 输入名称 → Enter，Tab 可显示候选。
- 文件：`:e 路径`、`:enew`、`:ls`、`:bn`、`:bp`、`:b 编号`、`:bd[!]`。
- 写盘：`:w`、`:w 新路径`、`:saveas 新路径`，`!` 显式允许覆盖。
- 退出：`:q`、`:q!`、`:wq`、`:x`；写盘失败不会退出或清除修改状态。
- `Ctrl+C`：关闭 grep、帮助、列表、菜单，或取消命令输入；有选区时先取消选区。
  编辑窗口复用 JOE 原版退出判断：最后一个视图有未保存修改时确认丢弃；有后台缓冲区先返回它，
  否则关闭编辑窗口，最后一个编辑窗口关闭后退出主窗口。多个视图共享同一缓冲区时，关闭非最后视图不提示丢弃。

`:recent` 打开居中的最近文件选择框，最多保留 200 个文件，最新在前，重复打开移到顶部。
长路径按显示宽度折行；溢出时显示滚动条，PageUp/PageDown 按屏幕页翻页，上下键或 Ctrl+P/N 选择，
Enter 打开，Esc / Ctrl+C 取消。打开前检查文件，已经不存在的条目提示后删除；权限或其他 I/O 错误保留记录。
恢复最近使用的只读/读写、文本/Hex、只读懒加载及软折行状态；当前其他缓冲区的未保存内容仍保留。
原有 Hex 编辑模式也可用 `:` 输入 Ex 命令（如 `:recent`），其他 Hex 键位保持原有方式。

个人配置统一放在 `~/.mj`，具体布局和迁移说明见 [个人配置](personal-profile.md)。

软折行是独立的显示选项，默认关闭：`Ctrl+T` → `Q Soft wrap` 切换；也可用 `:set wrap` / `:set nowrap` 明确开启、关闭。
开启后，已有长行按 Right Margin 与窗口正文宽度的较小值折行显示，调整边界、窗口大小或字号后即时重排。
不新增文件换行，不改变保存内容；原有 `W Word wrap` 仍独立控制输入时的硬换行，仅需软折行时请关闭它。
`j/k`、上下键与 `Ctrl+P/N` 仍按逻辑文件行移动，PageUp/PageDown、滚轮和鼠标定位使用屏幕行。
中文宽字符完整移到下一行，组合字符不拆分；续行的行号区域留空。Hex、Picture、隐藏 ANSI 模式和 shell 窗口使用原有显示。
命令行 `-softwrap` 或个人配置 `-softwrap` 可指定启用；`--softwrap` 指定关闭。

顶部状态栏显示绝对文件路径，鼠标拖选后复制；图形窗口双击可复制完整路径，显示被截断时也能复制全部。
路径选择不改变正文光标或 Vim 模式；macOS 的 `⌘C`、Windows 的复制操作也可复制所选路径。
控制台需开启 `-mouse`（或配置 `-mouse`），复制通过终端的 OSC 52 协议完成；终端不支持时可按住 Shift 拖选，使用终端复制。

已命名缓冲区的 `:w 新路径` 写出副本，`:saveas 新路径` 切换当前文件名。
路径可以含空格，也可在整个路径两端加双引号；Windows 反斜杠保持原意。
缓冲区编号在同一运行会话内稳定。切换文件保留未保存内容；`:bd` 和退出保护修改。
`:ls` / `:buffers` 使用只读分页列表，逐行显示完整文件路径，长路径自动换行，不再挤在一条状态消息中。
PageUp/PageDown 翻页，`q` / Esc 关闭；`%` 为当前缓冲区，`+` 为修改，`R` 为只读，`L` 为懒加载。
macOS 原生版会汇总所有 MiJoe 窗口（包括 grep 结果窗口）中的缓冲区，按窗口分组。
每个窗口有独立的缓冲区编号：关闭列表后，先用“窗口”菜单选择窗口，再用 `:b 编号` 切换其缓冲区。
`:bn/:bp/:b` 仍只切换当前窗口内的缓冲区；终端版的列表范围是当前 mj 进程。
内部寄存器独立于系统剪贴板。Windows Insert 模式支持 Shift+Insert 粘贴。
编码和换行沿用 JOE 的文件选项，已有文件不会因进入 Vim 模式而主动转换。

上述定位可用于 Visual 和 `d/c/y`，例如 `dfx`、`dFx`、`ctx`、`y%`、`v%d`；
次数可组合，如 `2d3fx`。`f/t` 的操作范围包含向右终点，`F/T` 向左时不包含原光标字符；
`d%` 包含括号两端，条件编译配对与数字百分比按整行操作。查找失败会取消待执行操作。
括号匹配按 Vim 的默认转义规则区分奇偶反斜杠，并跳过双引号和 C 单字符常量中的括号。
行为参考 [Vim motion 文档](https://vimhelp.org/motion.txt.html)，通过本机 Vim 做结果对照；
不包含自定义 `matchpairs`、matchit 插件或语言语法树匹配。

例如在行首执行 `Ctrl+V`、`2j`、`I`，输入 `// ` 后按 Esc，可给三行加相同前缀。
输入期间先显示首行修改，按 Esc 后应用到其余行。`Ctrl+V`、`2j`、`$`、`A` 则在每行行尾追加。
矩形按屏幕列计算：`I` 跳过没有到达插入列的短行，`A` 对短行补空格，插入位置落在 Tab 内时拆为空格。
支持中文输入和单行粘贴；输入期间移动光标、删除到原文或输入换行时，后续只保留首行的普通编辑。
再次按 `Ctrl+V` 或按 Esc 取消矩形选择，`v/V` 可切换为字符/整行选择。
行为参考 [Vim blockwise operators](https://vimhelp.org/visual.txt.html#blockwise-operators)。

Vim 模式保留 `Ctrl+K` 前缀绑定和 `Ctrl+T` 的 JOE 路径，菜单和提示框使用原有键位。
主题即时生效，跨会话保留沿用 JOE 的 `joe_state`；macOS 双击测试启动器关闭了状态写入，
重新启动不会记住本次主题选择。启动时固定主题可使用 `bin/mijoe -colors gruvbox 文件路径`。
界面中的中文支持列表源于 `docs/vim-help.txt`；修改后运行
`python3 tools/generate_vim_help.py` 更新供 VC6/UNIX 共用的嵌入头文件。

矩形删除、修改、复制粘贴、句子/段落/标签文本对象、Vimscript、完整 Ex 命令和强制重新加载
暂未实现。矩形模式请先使用 `I/A` 再输入或粘贴；未实现的命令会显示提示。

## 文本对象

`viw` 选择光标所在的整个单词，而非从光标到词尾；`diw` 删除、`ciw` 修改、`yiw` 复制相同范围。
`aw` 带上相邻空白；`iW/aW` 把没有空白隔开的单词和标点视作一个 WORD。
`iw` 停在空白上时选择空白，次数把空白段也计入；`aw` 的次数只计单词。
例如 `v2iw` 可以选中一个单词及后面的空白，`d2aw` 删除两个单词及相邻空白。

`i(`/`i)`、`i[`/`i]`、`i{`/`i}`、`i<`/`i>` 选择括号内部；把 `i` 换成 `a` 包含括号。
`ib/ab` 是圆括号别名，`iB/aB` 是花括号别名。支持跨行、嵌套及次数，如 `2di(`。
`i"/a"`、`i'/a'`、`i` + 反引号 / `a` + 反引号选择当前行的引号文本，跳过反斜杠转义的引号。
引号内对象使用次数 2 时包含引号；带 `a` 的引号对象还包含相邻空白。

上述对象供 Visual 和 `d/c/y` 共用，可带寄存器、撤销或用 `.` 重复修改；Visual 中可继续扩展范围。
普通模式单独按 `i/a` 仍进入插入模式。句子、段落、HTML/XML 标签对象及自定义 `iskeyword`、
`quoteescape`、`matchpairs` 选项尚未提供。行为以默认 Vim 为对照。

## UNIX 构建

需要 C 编译器、make、Autoconf、Automake，以及可选的 terminfo/termcap 开发库。

```sh
sh autojoe
mkdir -p build/unix
cd build/unix
../../configure --prefix="$PWD/install"
make -j4
make install
./install/bin/joe
```

Windows XP 构建仍使用 `windows/vc6/build.bat Release package`。
各平台测试结果分别记录，Wine 运行不能替代 XP 实机或虚拟机验收。

## 大文件

超过 512 MiB 时可选择只读懒加载；二进制文件自动进入 HEX 模式。加载策略、搜索及复制边界见 [大文件说明](large-files.md)。

## Emacs 风格移动与当前文件 grep

新增内置 `awk`、`head -n`、`more`、`less`，与 `grep` 可通过 `|` 任意组合。
例如 `:grep ERROR | awk '{print $2,$5}' | head -n 20 | less`；
`-f` 导出整条管道的最终纯文本，console 新建缓冲区、macOS 原生版新建窗口。
语法、示例、分页操作及处理上限见 [内置文本管道](internal-pipelines.md)。

三种模式均支持 `Ctrl+A/E` 到行首/行尾、`Ctrl+P/N` 上下移动、`Ctrl+B/F` 前后移动一个字符。
`Ctrl+K` 前缀优先，保留 `Ctrl+K Ctrl+B` 标记起点与 `Ctrl+K Ctrl+F` 查找等原有组合。
Insert 下 `Ctrl+E` 定位到换行符之前，可直接追加；Ctrl+B/F 可以跨行移动。`:command` 输入行使用 cyan。

`:grep 表达式` 搜索当前文件，不调用 shell。普通文本使用 JOE 正则；只读懒加载以字面文本流式搜索。
结果框的左右方向键按显示列移动统一的正文视口，所有结果一起滚动，行号固定；标题 `X` 显示起始列。
上下选择结果时保留水平位置，窗口变宽时自动限制偏移，重新 grep 从最左侧开始。
结果预览沿用原来每行约 1 KiB 的长度上限。
结果以“行号: 行内容”居中显示，宽约 3/4、高约 2/3，总面积约为半个窗口。
方向上下键、Ctrl+P/N、j/k 选择并即时预览对应位置；PageUp/PageDown 翻页，Home/End、g/G 到首尾。
Enter 保留预览位置并关闭，Esc/Ctrl+C/q 关闭并恢复原光标、水平滚动和顶部位置。
列表随窗口缩放重新布局，弹出期间禁止编辑、保存和切换底层缓冲区。
弹出列表每个匹配行一项；最多保留 10000 行结果，达到上限显示 `limit` 并停止扫描，行内容只显示开头预览。

`:grep -f 表达式` 将完整匹配行写入新的纯文本临时窗口，以“行号: 内容”排列，不受弹出列表每行约
1 KiB 的预览限制。例如 `:grep -f ERROR`、`:grep -f "WARN.*timeout"`。
console/终端版在当前编辑窗口中新建结果缓冲区，`:ls` 同时列出原文件与结果；用 `:bn/:bp` 或
`:b 编号` 切换，`:bd` 关闭结果缓冲区（丢弃未保存结果用 `:bd!`），不再额外创建 JOE 编辑窗口。
原文件、光标和未保存内容保留。
macOS 原生版继续打开独立窗口，Windows 图形版保留原有的新编辑窗口行为。
结果是可编辑的未命名缓冲区，使用 `:saveas 路径` 或窗口“保存”来保存；未保存退出时仍有保护。
可用 `:grep -f -- -f` 查找字面 `-f`，`--` 终止选项解析。搜索规则和普通 grep 一致。
最多导出 10000 个匹配行，达到该上限时在结果末尾注明；总输出限制 64 MiB，超过时取消导出并提示
缩小搜索范围。长行和懒加载 UTF-16 以固定大小缓冲区分块导出，传输临时文件在窗口导入后删除。

## 寄存器与命令栏粘贴

支持会话内未命名 `"`、复制 `0`、删除历史 `1`–`9`、小范围删除 `-`、命名 `a`–`z`、
大写追加 `A`–`Z` 以及黑洞 `_` 寄存器。例如 `"ayy` 复制当前行到 a，`"ap` 粘贴，`"_dd` 删除但保留原有寄存器。
默认复制更新 `0`；命名复制不覆盖 `0`，后续删除也不覆盖复制寄存器 `0`。

在 `:`、`/`、`?` 命令栏或 Insert 中，按 `Ctrl+R` 再按寄存器名插入内容。例如选择 WARN 后，
输入 `:grep `，按 `Ctrl+R`、`0`、Enter，即可查找选中的内容。
Visual 选择或 Ctrl+K Ctrl+B / Ctrl+K Ctrl+K 标记后直接进入命令栏，会将选择复制到 `0`。
原生复制菜单与 JOE 块复制也会更新复制寄存器。
命令栏还可读取 `/`（搜索表达式）、`:`（上次 Ex 命令）、`%`（文件名）；普通模式 Ctrl+R 仍然是重做。
命令栏多行内容转换为空格，粘贴本身不执行命令；超长内容整次拒绝。矩形标记作为多行文本处理。
当前不支持系统剪贴板 `+`/`*`、表达式 `=` 和跨会话持久化寄存器。

Grep 弹窗使用选中行作为定位指示并隐藏文本光标，关闭后恢复；不再重复清空和重绘整个列表。

## 查看寄存器与 F5/F6 宏

输入 `"` 后，底部回显寄存器选择提示；继续输入 `a` 等名称会显示所选寄存器，Esc 取消。
`:reg` / `:registers` 查看类型、字节数及内容；`:reg a`、`:reg 0a` 只看指定项。
控制字符会转义显示，每个寄存器预览前 16 KiB，并明确标记截断；PageUp/PageDown 翻页，q/Esc 返回。

F5 开始键盘录制，再次 F5 保存；录制中状态栏持续显示 `REC` 和键数。F6 回放最近保存的宏。
建议在 Normal 模式开始、结束和回放；如果在 Insert 或 Visual 开始录制，回放时也必须处于相同模式。
`:macro`（别名 `:macros`）查看保存的宏或正在录制的按键序列，控制键显示为 `<Esc>`、`<C-K>` 等名称。

例如 Normal 下按 F5，然后 `I// `、Esc、`j`，再按 F5；F6 会在下一行重复添加注释前缀。
录制包含编辑区键盘输入、Ex 命令、中文、终端粘贴和 JOE Ctrl+K 组合键；鼠标及原生菜单操作不录制。
宏只保存在当前进程中，最多 65536 个按键事件；超过上限丢弃新录制、保留原宏。
录制期间 F6 不启动回放，回放不能递归；Ctrl+C 中断，命令错误会停止。新录制为空时保留之前的宏。

## Ex 文本替换

- `:s/foo/bar/` 替换当前行第一处；`:s/foo/bar/g` 替换当前行全部。
- `:%s/foo/bar/g` 全文替换；`:2,10s/foo/bar/g` 指定行范围。地址支持 `.`、`$`、数字及 `+/-` 偏移。
- Visual 选择后按 `:` 输入 `s/foo/bar/g`，自动填入 `'<,'>` 行范围；其他命令保留原用法。
- 标志：`g` 每行全部，`i` 忽略大小写，`I` 区分大小写，`c` 逐项确认，`e` 无匹配不报错。
- 确认时 `y` 替换、`n` 跳过、`a` 全部、`l` 替换当前项并结束，`q` / Esc / Ctrl+C 停止；已确认部分保留。
- 单次 `u` 撤销整次替换，Ctrl+R 重做。空旧串复用上次搜索，单独 `:s` 重复上次替换，不继承标志。
- 支持 `:substitute` 和其他分隔符，例如 `:s#/old/path#/new/path#g`。

正则使用 Vim 默认 magic 的常用子集：`. * [] ^ $`、`\(分组\)`、`\+`、`\?`、`\=`、
`\{m,n}`、`\<` / `\>` 单词边界及 `\c` / `\C`。数量上限 1000，最多 9 个捕获分组。
普通括号和加号按字面匹配。替换串中的 `&` / `\0` 是整个匹配，`\1`…`\9` 是分组，
`\&`、`\\` 插入字面字符，`\r` 插入换行，`\t` 插入 Tab，`\n` 插入 NUL。

只读、Hex 和懒加载文件拒绝替换。跨行正则、模式中的反向引用、交替 `\|`、magic 修饰、
表达式、大小写转换和上次替换串展开、尾随计数及 Ex 管道尚不支持；对应语法会报错。
替换使用独立的行内贪婪匹配入口，保留原有搜索/grep 的匹配规则。

## 行位置百分比

右上角 R / C 后显示“当前逻辑行 ÷ 全部逻辑行 × 100”的整数百分比，向下取整。
末尾换行不多算一行，空文件显示 100%；软折行不增加总行数。Hex 按每 16 字节一行计算。
只读懒加载文本尚未掌握全部行数时显示 --%，不会为了百分比扫描整个文件；原有 RO-LAZY 字节进度独立保留。

## 临时字面高亮

```vim
:set-hl "gogogo 123"
:set-hl gogogo 123
:set-hl "two words" ERROR
:set-hl
:clear-hl
```

第一条将包含一个空格的 `gogogo 123` 作为完整短语匹配。第二条分别匹配 `gogogo` 和 `123`，
中间空白不高亮；第三条混用短语与单词。多次添加会合并、去重，不带参数时显示当前列表，
`:clear-hl` 清除当前文件的全部临时词。

匹配区分大小写，采用字面子串，`.*[]()|` 等正则符号没有特殊含义。双引号用于把含空格的内容
组合成一项，`\"` 和 `\\` 分别表示字面引号和反斜杠；不支持跨逻辑行的短语。
临时词使用终端调色板的亮黄色背景、黑色前景。选区和 `/` 搜索的高亮优先，`:noh` 只清除搜索高亮。

临时词只属于当前打开的文件缓冲区，切换到别的缓冲区后回来仍保留；真正关闭缓冲区（如 `:bd`）
或退出程序后丢弃。`:recent` 继续保存文件及其打开模式，不把临时词作为文件属性写入 `.recent` 或 `state`。
若使用命令历史，`:set-hl` 的输入文本会像其他命令一样保留在 `.history`，重开文件不会自动执行它。
从 `:recent` 重新打开已关闭文件时不恢复临时词；选中仍在内存中的缓冲区则继续使用它当前的临时词。

该功能独立于语法高亮开关，支持只读、大于 16 MB 且自动关闭语法高亮的普通文本以及只读懒加载。
只检查显示区域及最长词覆盖边界，不扫描全文，不修改文件、不产生撤销记录；软折行中的匹配仍按原文计算。
Hex 视图暂不显示或添加临时词，切回文本后已有临时词继续生效。

每个缓冲区最多 32 项，每项最多 1024 个 UTF-8 字节，总计不超过 8192 字节。
空字符串、未闭合引号、控制字符或超限会拒绝整次命令，原有临时词保留。

## 命令栏历史

`:history` 在只读分页区域列出最近 200 条已提交的 `:`、`/`、`?` 命令栏输入，最新在前。
显示全局递增编号和来源：`INPUT` 是手动输入，`REC` 是录制宏时执行，`PLAY` 是回放宏时执行。
宏中每次实际提交的命令都独立保留；重复、失败的命令也会记录，宏的普通编辑键不进入此列表。

PageDown / PageUp 或 Space / `b` 翻页，`q` / Esc / Ctrl+C 关闭并返回原文件。
Enter 只翻页，不执行所展示的命令。取消、空白输入、原生菜单操作和 `:history` 查询本身不记入历史。

历史保存在 `~/.mj/.history`，不受 `joe_state` 开关影响，跨文件、窗口和重启保留。
多个窗口以文件锁及原子替换合并更新，超过 200 条时删除最旧记录；文件无效或无法读取时保留原文件，
不影响原命令执行。该功能从安装此版本后开始累计，不能补回旧版本没有保存的命令。

临时高亮的 `:set-hl` 输入可作为普通命令出现在历史中，但列表不会自动执行命令，
因此重开文件仍不会恢复临时高亮。宏的完整按键继续使用 `:macro` 查看。

默认 Tab 宽度为 4 列（窗口和控制台一致）；已有 Tab 按此宽度显示，按 Tab 仍插入制表符。
可在 Ctrl+T 的 Tab width 中调整；显式的文件类型或个人设置仍优先。
