# 大文件与二进制文件

普通文件大于 **512 MiB（536,870,912 字节）** 时，先采样识别类型，再让用户选择：

- **只读懒加载**：默认推荐；终端按 `L` 或 Enter。
- **正常打开**：终端按 `N`，使用原有完整编辑缓冲区，可能消耗大量内存和临时磁盘空间。
- **取消**：终端按 Esc、Ctrl+C 或 `C`，返回原缓冲区并保留原有修改及位置。

macOS 原生窗口以对话框显示相同选项。小于或等于阈值仍使用原有加载方式。受构建的编辑偏移上限限制时，禁止完整打开；例如 VC6/XP 的传统编辑缓冲区不能完整容纳超过 2 GiB 的文件。

识别到二进制内容后，自动使用十六进制（HEX）视图；超过阈值同样先选择打开方式。识别依据头部最多 64 KiB 的 BOM、UTF-16 特征、NUL/控制字符和常见文件签名，不是扫描整个文件来判定类型。UTF-16 文本不会因 NUL 字节直接被当成二进制。

## 只读懒加载的行为

- 保持原文件的只读描述符，按需读取约 **1 MiB** 的附近窗口，窗口随移动被替换；不把全文件读入编辑器，也不预先复制到交换文件。UTF-16 转码与偏移映射会额外占用固定窗口大小的内存，1 MiB 不是进程总内存上限。
- 使用独立的 **64 位原文件字节偏移**；HEX 地址为原文件绝对地址。支持跨越 4 GiB，具体文件大小仍受操作系统与文件系统限制。
- 禁止修改、撤销修改、保存和另存为，包括强制保存。底层写文件入口也拒绝写出懒加载缓冲区，防止误保存片段。
- 关闭语法高亮、标题扫描、行号边栏及其他需要扫描大量内容的处理。
- `gg` / `G` 到文件首尾；`数字%` 按**字节比例**跳转；`:数字` / `数字G` 按行号跳转。文本换区后若无法确定全局行号，`R` 显示 `?`，状态栏 `B 当前位置/文件大小` 始终显示原文件字节位置。超长行从中段加载时，未知列号也显示 `?`。
- `/字面文本`、`?字面文本`、`*`、`n` / `N` 支持跨区域流式搜索。懒加载只支持字面匹配及完整单词边界，不支持一般正则表达式；普通打开保留原有正则功能。
- 按行号跳转和搜索会按需顺序读取文件，耗时可能随距离增长；Esc / Ctrl+C 取消。不会创建随文件增长的完整行号索引。
- 可复制当前加载区域内的选择；换区时清除选择。原生菜单的全文件全选不可用，同一缓冲区不能分屏共享；可在独立窗口重新打开。
- 检测到原文件大小或修改时间变化后，停止换区和搜索，请关闭后重新打开。此模式不会锁定外部写入进程，也不提供文件快照。

## 命令行

```sh
mj -lazy 文件名                 # 小文件也直接以只读懒加载打开
mj -large_threshold 512 文件名  # 提示阈值，单位 MiB，默认 512
```

`mj`、只读入口 `rmj` 和十六进制入口 `xmj` 共用文件打开机制。`-lazy` 的只读限制不能通过选项菜单解除；要编辑请重新选择正常打开。
